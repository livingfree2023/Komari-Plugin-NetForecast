# 账单周期已用流量修复

当月已用、实际累计折线和额度预测共用统计时区内的账期增量。周期由节点到期日或既有重置日配置确定。每日柱状图继续使用独立的采样增量。

- 以每日记录的本地日期归入 `[账期开始日, 今日]`，同一天取最后一条。该口径兼容旧版存储中带偏移的今日时间戳。
- 网卡累计计数器仅作为采样打点使用。有基准时按差值及计数器重置规则计算增量。首次采样建立基准，历史拉取失败时沿用已保存的分日数据。
- 后端在合并前端每日记录前更新实时采样基准，重叠日期以本次同步记录为准。完整同步、单节点重试、只读诊断与浮窗使用相同的预测逻辑。
- 7 日加权均速仍可使用上一个账期的完整日。按本地日期识别完整日，避免旧快照中的今日标记长期排除该日。

验证包括周期边界、重复和未来记录、冷启动与重启、各计费模式、HTML 打点与 `/overview` 路由。对目标节点的真实诊断快照进行本地回放，再核对 ZIP 内的版本与内容。
